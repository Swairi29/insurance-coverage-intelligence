repository.

_Snapshot taken: 2026-09-21 (branch `main`)._

---

## `agents/` — the agent pipeline

Each agent follows the same internal shape: `main.py` (entrypoint), `api.py` (HTTP
layer), `service.py` (agent logic), plus agent-specific modules and a `tests/` folder.

```text
agents/
├── __init__.py
│
├── risk_agent/                     # 1. Risk Profiling Agent (port 8001)
│   ├── __init__.py
│   ├── main.py
│   ├── api.py
│   ├── service.py
│   ├── nlp.py                      # spaCy extraction from the business profile
│   ├── prompts/
│   ├── rules/
│   └── tests/
│       └── test_risk_api.py
│
├── policy_agent/                   # 2. Policy Intelligence Agent
│   ├── __init__.py
│   ├── main.py
│   ├── api.py
│   ├── service.py
│   ├── document_processor.py       # PyMuPDF / OCR
│   ├── retriever.py                # TF-IDF, BM25, ChromaDB
│   └── tests/
│       └── test_policy_api.py
│
├── coverage_agent/                 # 3. Coverage & Gap Analysis Agent
│   ├── __init__.py
│   ├── main.py
│   ├── api.py
│   ├── service.py
│   ├── rules.py                    # deterministic coverage decisions
│   ├── interpreter.py              # LLM-assisted clause interpretation
│   └── tests/
│       └── test_coverage_api.py
│
└── explanation_agent/              # 4. Explanation & Recommendation Agent
    ├── __init__.py
    ├── main.py
    ├── api.py
    ├── service.py
    ├── rag.py                      # RAG over cited policy clauses
    ├── validator.py                # citation grounding and output checks
```

## `frontend/` — React web app

Vite + React 18 + TypeScript, with React Router, TanStack Query, React Hook Form and Tailwind.
Tests (`*.test.ts(x)`) sit next to the code they test. See
[frontend-plan.md](frontend-plan.md) for the design and [architecture.md](architecture.md#frontend).

```text
frontend/
├── index.html
├── package.json                    # scripts: dev, dev:mocks, build, lint, typecheck, test
├── vite.config.ts                  # dev proxy to the gateway (/api, /health), Vitest settings
├── tailwind.config.ts              # colours (brand, status) defined once
├── .env.example / .env.mocks       # VITE_USE_MOCKS, VITE_API_BASE_URL (nothing secret)
├── public/
│   └── mockServiceWorker.js        # generated by MSW, used only by `npm run dev:mocks`
└── src/
    ├── main.tsx, App.tsx           # entry point and routes
    ├── api/                        # gateway calls: client (errors, upload progress), types,
    │                               #   auth, policies, analyses, health
    ├── auth/                       # AuthProvider, token storage, RequireAuth, safe redirects
    ├── components/                 # StatusBadge, EvidenceList, AiLabel, ConfidenceLabel,
    │   │                           #   ErrorMessage, Disclaimer, AgentStatus, icons
    │   ├── Layout/AppLayout.tsx    # header, navigation, logout
    │   ├── form/                   # TagInput, TriStateField (Yes / No / Not sure)
    │   └── ui/                     # Button, TextField, Alert, Spinner, Skeleton
    ├── lib/                        # labels, formatting, profile draft, result helpers
    ├── pages/
    │   ├── Landing.tsx, NotFound.tsx
    │   ├── auth/                   # Login, Register
    │   ├── Dashboard.tsx, BusinessProfile.tsx, Policies.tsx
    │   ├── NewAnalysis.tsx         # policy choice, progress screen, errors
    │   ├── History.tsx
    │   └── Results/                # ResultsPage + Report, Coverage, Risk profile tabs
    ├── mocks/                      # MSW mock API: handlers, in-memory db, fixtures/
    └── test/                       # test setup and render helpers
```

## Notes

- `.gitkeep` files hold otherwise-empty directories in git; they are omitted from the
  trees above.
- `data/sample_policies/` is deny-by-default in `.gitignore`, with `synthetic/` and
  `adversarial/` explicitly re-included. Real policy documents under `real/` are never
  committed.
- `data/index/`, `data/uploads/` and `data/app.db` are runtime artefacts and gitignored.
- `frontend/node_modules/` and `frontend/dist/` are gitignored; run `npm install` in `frontend/`.
- Secrets live in `.env` (gitignored); `.env.example` documents the expected variables.
